How it works

A crash, a usage limit or a full context window is a hand-off, not a restart.

01

Plan

Muse Wonder plans the task and asks only the questions whose answers change what gets built.

02

Build

Any agent builds in its own git worktree: Muse Code, the Stint agent, or one you bring.

03

Hand off

When a run ends, however it ends, Stint writes a packet from the log and the diff. The next agent starts from that alone.

04

Verify and approve

Stint runs the tests itself, Muse Glimmer reviews on your laptop, and only you merge.

Why not just resume the session?

Muse Code resumes its session. Stint carries the task.

Inside one agent

  • A worktree for each subagent
  • A JSONL log of the session
  • muse resume after a crash

Above every agent, with Stint

  • A packet any agent continues from
  • Tests run by Stint, not reported by the agent
  • Review on your laptop, with the network off
  • Goals split into tasks that wait on each other
  • Nothing merges until a person approves

They work together: Muse Code drives Stint over MCP.
