# Support

Supported platforms, what each part of Stint needs, and what happens without it are in [`setup.md`](setup.md#platforms). For a problem on your machine, run `stint doctor`: it prints one line per check, with the command that fixes it. The README's [Troubleshooting](../README.md#troubleshooting) table lists the eight most likely failures.

To report a bug or ask for a feature, open an issue on GitHub. To report a security problem, see [`SECURITY.md`](../SECURITY.md).
