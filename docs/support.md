# Support

This page says where to go when Stint does not work for you.

- **Platforms and requirements:** [`setup.md`](setup.md#platforms) lists the supported platforms, what each part of Stint needs, and what happens without it.
- **A problem on your machine:** run `stint doctor`. It prints one line per check, with the command that fixes it.
- **Common failures:** the README's [Troubleshooting](../README.md#troubleshooting) table lists the eight most likely failures.
- **Bugs and feature requests:** open an issue on GitHub.
- **Security problems:** see [`SECURITY.md`](../SECURITY.md).
